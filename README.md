# Власта-Консалтинг — сайт

Статический сайт (без фреймворков и внешних зависимостей). Все страницы
генерируются из данных в `content/` скриптом `tools/build.mjs`.

```
content/          ← весь контент (единственное, что нужно править)
  site.json         услуги, подход, история, ассоциации, клиенты, команда
                    (английский — в полях с суффиксом _en)
  news.json         74 новостных материала
  cases.json        12 кейсов
  geo-map.json      контуры стран для карты (генерируется make-map.mjs)
  en/news.json      те же материалы на английском
  en/cases.json     те же кейсы на английском
tools/
  build.mjs         генератор: content → HTML + sitemap.xml + robots.txt
  check.mjs         проверка битых ссылок, отсутствующих файлов и alt у картинок
assets/
  css/style.css     дизайн-система
  js/main.js        интерактив
  img/…             изображения (новости, кейсы, клиенты, ассоциации, команда)
```

## Сборка

```bash
node tools/build.mjs ru   # русская версия → корень сайта
node tools/build.mjs en   # английская версия → /en/
node tools/check.mjs      # проверка ссылок и ресурсов по обеим версиям
```

Русский — язык по умолчанию. Английские страницы собираются из
`content/en/news.json`, `content/en/cases.json` и полей `*_en` в
`content/site.json`; если английского значения нет, подставляется русское.

Сборка создаёт: `index.html`, `services.html`, `about.html`, `cases.html`,
`news.html`, `contacts.html`, `privacy.html`, `cases/<slug>.html` (12),
`news/<slug>.html` (74), `sitemap.xml`, `robots.txt`.

Локальный просмотр:

```bash
node server.js           # http://localhost:8099
```

## Публикация новостей

Новость — это один объект в массиве `content/news.json`. Добавьте его
**в начало** массива (порядок в файле = порядок на сайте, новые сверху)
и пересоберите сайт.

```json
{
  "id": 83,
  "slug": "kratkiy-slug-na-latinice",
  "title": "Заголовок в списке новостей",
  "h1": "Заголовок на странице материала (может быть длиннее)",
  "dateIso": "2026-08-01",
  "dateDisp": "1 августа 2026",
  "category": "Контрафакт",
  "cluster": "Защита бренда и ИС",
  "metaTitle": "SEO-заголовок для вкладки и выдачи",
  "metaDesc": "SEO-описание, 150–180 символов.",
  "keywords": ["ключевая фраза", "вторая фраза"],
  "excerpt": "Короткий анонс для карточки, 1–2 предложения.",
  "img": "assets/img/news/01082026.jpg",
  "video": null,
  "links": [{ "url": "https://example.com/", "text": "Источник" }],
  "body": [
    "Первый абзац.",
    "Второй абзац. Внутри допустимы <a href=\"https://...\">ссылки</a>, <b>полужирный</b> и <i>курсив</i>."
  ]
}
```

**Поля**

| Поле | Обязательное | Примечание |
|---|---|---|
| `id` | да | уникальное число |
| `slug` | да | латиница и дефисы — станет адресом `news/<slug>.html` |
| `title` / `h1` | да | `h1` может совпадать с `title` |
| `dateIso` | да | `ГГГГ-ММ-ДД`, используется в sitemap и schema.org |
| `dateDisp` | да | как показывается людям |
| `cluster` | да | тема для фильтра — см. список ниже |
| `metaTitle` / `metaDesc` | да | SEO |
| `excerpt` | да | текст в карточке |
| `img` | да | путь от корня; положите файл в `assets/img/news/` |
| `video` | нет | `null`, либо см. ниже |
| `links` | нет | `[]` если источников нет |
| `body` | да | массив абзацев |

**Темы (`cluster`)** — влияют на фильтр на странице новостей:
`Защита бренда и ИС`, `Корпоративная безопасность`, `Управление рисками`,
`Потребители и регулирование`, `Отраслевые связи`, `Новости отрасли`.

**Видео.** Два варианта:

```json
"video": { "type": "mp4",   "src": "https://vlasta-s.com/news/file.mp4" }
"video": { "type": "embed", "src": "https://www.youtube.com/embed/VIDEO_ID" }
```

`embed` подходит для YouTube, VK Video и других плееров с `iframe`.
Крупные mp4-файлы (десятки и сотни мегабайт) намеренно **не** хранятся в
репозитории — они отдаются с продакшн-домена по прямой ссылке.

**Картинки.** Кладите в `assets/img/news/`. Оптимальный размер — 1200×630 или
шире, соотношение около 16:10; карточки и открытая графика в соцсетях
обрезаются автоматически. Если подходящего фото нет, подберите нейтральное
тематическое изображение — пустая карточка выглядит хуже, чем общее фото.

После правки:

```bash
node tools/build.mjs ru && node tools/build.mjs en && node tools/check.mjs
git add -A && git commit -m "Новость: краткое описание" && git push
```

Деплой на `adva.media/vlasta` произойдёт автоматически (GitHub Actions).

## Кейсы

Устроены так же — `content/cases.json`. Тело кейса разбито на блоки:

```json
{
  "slug": "primer-keysa",
  "n": 13,
  "category": "Защита бренда",
  "title": "Название кейса",
  "intro": "Аннотация для карточки и подзаголовка.",
  "metric": "−85% точек",
  "tags": ["тег", "ещё тег"],
  "img": "assets/img/cases/13.jpg",
  "sections": [
    { "h": "Ситуация", "p": ["абзац", "абзац"] },
    { "h": "Проблема",  "p": ["абзац"] },
    { "h": "Решение",   "p": ["абзац"] },
    { "h": "Результат", "p": ["абзац"] }
  ]
}
```

`metric` можно оставить `null` — тогда плашка с цифрой не выводится.

## Дизайн-система

Палитра из брендбука (`Власта логобук концепция 3.pdf`, стр. 5):

| Pantone | HEX | Роль в интерфейсе |
|---|---|---|
| 7547 C | `#11192B` | заголовки, тёмные секции, футер |
| 7546 C | `#1D2537` | тёмные поверхности |
| 5405 C | `#344361` | акцент: кнопки, ссылки, активные состояния |
| 657 C | `#C5CDDA` | границы, светлые заливки, линии гильоша |
| 877 C | `#8C9091` | второстепенный текст, подписи |

Шрифт — **Montserrat** (по брендбуку), используется от ExtraLight 200
в крупных заголовках до Bold 700 в акцентах.

Мотив — **гильош**: тонкая гравированная сетка, язык защитной печати
(банкноты, сертификаты, знаки подлинности). Прямая отсылка к предмету работы
компании — противодействию подделкам.

Тёмная тема включается кнопкой в шапке и сохраняется в `localStorage`
(ключ `vlasta-theme`), по умолчанию следует настройке системы.

## Что осталось

- **Английские тексты кейсов и новостей** взяты с текущего сайта
  vlasta-s.com. Три кейса из .docx переведены нами — стоит вычитать.

  это сделано намеренно, чтобы staging-копия на `adva.media` не
  конкурировала в поиске с будущим продакшном.
